# Transport Raito – website (portfolio version)

Website I built for a transport company. For my portfolio the company is **anonymized**:
the name, logo, contact details, people and photos are replaced with fictional ones.

## Pages
- `index.html` – main company website (my own HTML/CSS/JS, no frameworks)
- `vtc-site.html` – older virtual trucking community site (built on the Definity HTML template by ajdethemes, I customised layout, sections and scripts)
- `404.html`, `pages/maintenance.html`

## What I did
- Built the layout from the Figma design
- Responsive layout + mobile menu
- Services slider, count-up numbers, sticky header, language picker (vanilla JS)
